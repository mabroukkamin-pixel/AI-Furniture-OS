# Experimental World Prototype

This directory preserves an incomplete, dormant prototype for a future world, knowledge, and decision layer.

It is not part of the canonical production pipeline and must not be imported by active runtime modules.

Known limitations:

- WorldState is not implemented.
- The prototype has no active integration contract.
- Its original test is empty and remains under tests/legacy.
- Imports may reflect the prototype's former location.

Any future activation requires a separate architecture review, implementation contract, and active test suite.
