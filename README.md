# AI Furniture OS

AI Furniture OS is an intelligent production pipeline for automated furniture advertising creation.

## Version

1.0.0

## Overview

AI Furniture OS transforms furniture products into premium marketing concepts using AI decision engines.

The system analyzes:

- Product identity
- Materials
- Style
- Environment
- Lighting
- Camera
- Composition
- Branding
- Marketing strategy

Then generates a complete creative direction and production prompt.

## Architecture

Main modules:

- Brain Engine
- Expert Pipeline
- Knowledge System
- Reference Library
- Design DNA Engine
- Prompt Compiler
- Production Manager

## Pipeline Flow
